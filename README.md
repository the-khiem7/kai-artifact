## Add an artifact

1. Create `artifacts/<slug>/index.html` (`<slug>` is lowercase kebab-case, e.g. `aws-cost-report`).
2. Give the page a `<title>`, a `<meta name="description">`, `<html lang>` and `<meta name="keywords">` (lowercase kebab-case topics) - they become the name, description and map links on the home page and in the table above.
3. Push to `main`. The workflow publishes the page at `https://the-khiem7.github.io/kai-artifact/<slug>/` and updates this README. The site adds a small floating dock to the published copy only; your file is not changed.

## Add a document

1. Create `documents/<slug>.md` with the frontmatter described in `.claude/skills/knowledge-distill/references/note-format.md`, or let the `knowledge-distill` skill turn a messy source into notes.
2. Run `uv run .claude/skills/knowledge-distill/scripts/check_notes.py documents`. The build runs the same check.
3. Push to `main`. The page appears at `https://the-khiem7.github.io/kai-artifact/docs/<slug>/`.
