# kai-artifact

Personal artifact registry. Each artifact lives in its own folder under `artifacts/` and is published by GitHub Pages with its own shareable link.

Browse all artifacts: https://the-khiem7.github.io/kai-artifact/

## Add an artifact

1. Create `artifacts/<slug>/index.html` (`<slug>` is lowercase kebab-case, e.g. `aws-cost-report`).
2. Give the page a `<title>` and a `<meta name="description">` - they become the name and description in the table above.
3. Push to `main`. The workflow publishes the page at `https://the-khiem7.github.io/kai-artifact/<slug>/` and updates this README.

Full rules for agents and contributors: [AGENTS.md](AGENTS.md).
