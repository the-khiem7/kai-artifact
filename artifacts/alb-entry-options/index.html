Decision

S2 chosen by the Solution Architect on 2026-10-14. The ALB stays in the Project 1 state for now (option A); moving it to a platform state (option B) stays optional.
Why S2 was recommended: Same 0 USD cost, a failure stays inside the Project 2 path, and there is no Host header dependency. Moving the ALB to a platform state later (option B above) gives it a neutral owner as more projects join.
Precondition: two origins can target one ALB (E2), tested by the first Project 2 apply→If not: fall back to S4

Questions for the architect

  1. Is a shared entry tier acceptable in UAT?Or should isolation (S4) win for 18.40 USD per month?
  2. Should UAT mirror the intended production topology?One ALB per project, or shared. UAT should test the shape production will use.
  3. Will Project 2 and Project 1 have different owners or release schedules?Different owners favour a platform state (B) or S4.
  4. Does the shared platform (ALB, VPC, cluster) need an explicit owner?Option B assumes yes.
