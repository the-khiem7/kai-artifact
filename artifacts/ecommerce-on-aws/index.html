E-commerce platform on AWS

Customers reach a Fargate-based commerce platform through Route 53, CloudFront and an Application Load Balancer; payments arrive by webhook, data flows to Aurora and an analytics lake, and a Bedrock agent answers assistant questions.

The six flows
  1. Customer web. Customers and support staff resolve the domain in Route 53, pass CloudFront and WAF, and the load balancer sends requests to the ECS tasks.
  2. Payments. The payments gateway posts webhooks to SQS; a Lambda confirms each payment to the monolith, and a second Lambda calls the gateway back through the NAT gateway.
  3. Shipping. The shipping adapter Lambda reaches the carriers through the NAT gateway and the internet gateway.
  4. Data and analytics. The ECS tasks write to the Aurora writer, which syncs to the reader, feeds the data lake and Glue, Athena and QuickSight, and is backed up by AWS Backup.
  5. AI assistant. The assistant API calls the Bedrock agent, which looks up live data through a Lambda (DynamoDB and the reader) and policy text in the knowledge base on S3 vectors.
  6. Delivery. DevOps pushes code, GitHub Actions builds the images and pushes them to ECR.
