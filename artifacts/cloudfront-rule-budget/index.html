Why port 8081 cannot use the CloudFront prefix list

A security group has 60 rule slots. One rule that points at the CloudFront prefix list uses 55 of them.

Shared ALB · ap-southeast-1 · read 2026-10-14

1 · What the CloudFront prefix list is

One shared list. It is not one list per distribution. AWS counts its full size, 55, because CloudFront can add ranges at any time.

2 · The same list, used by two rules, is counted twice

The cost comes from each rule that points at the list, not from a new distribution.

3 · The 60 slots of the ALB security group

prefix-list rule (55)security-group rule (1)does not fitfree

5 · Common misreadings

Sounds rightActually
A new distribution adds 55 more IPsOne list serves all of CloudFront. A new rule that points at it adds 55.
55 means 55 IP addresses55 is the reserved size of a list of IP ranges. Each range holds many addresses; 46 ranges exist today.
The fix reuses Project 1's IP rangesThe fix changes what the rule points at: a security group (1 slot) instead of a list (55).
