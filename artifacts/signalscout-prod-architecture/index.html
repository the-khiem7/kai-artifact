Reading notes
  • Source. Drawn after docs/assets/architect-v1.png. The region is ap-southeast-1 as set in the Terraform pack; the image says us-east-1.
  • Management does not write results. The Lambda webhook path writes S3 then DynamoDB after Langfuse scores a run (steps 9 and 10).
  • Retry loop. A low score re-invokes Management with the critique and the same runtimeSessionId, up to the retry ceiling, then needs_human_review.
  • Gaps carried over. WAF placement and AgentCore Memory appear in no closed decision (open gaps G4 and G3). v1 draws no Langfuse trace arrow from Management, and one shared Lambda serves trigger and webhook; the later v2 split them.
